# [III]Stingers

IIIStingers is a plugin that brings the police spike strips feature from Vice City to GTA 3!

# Installation

* Download the archive from [Releases section](https://github.com/Fire-Head/IIIStingers/releases)
* Manual install:
  * Extract `IIIStingers.asi` and `IIIStingers.ini` into your GTA 3 root or `scripts/` directory
  * Add `plc_stinger.dff` and `plc_stinger.txd` to your `models\gta3.img` with a IMG editor.
  * Add `plc_stinger.col` to your `models\Col\generic.col` with a COL editor.
  * Add the content of `to generic.ide.txt` to `objs` section of your `data\maps\generic.ide` with a notepad.
* modloader install:
  * Extract the `III.Stingers.7z/files/modloader/stingers` directory into your `modloader/` directory.
  * Extract `IIIStingers.asi` and `IIIStingers.ini` into the `stingers/` subdirectory inside your `modloader/`.
* Download and install [[III]BurstableTyres](https://github.com/Fire-Head/IIIBurstableTyres)(optional)

> [!NOTE]
> The plugin doesn't require ASI loader, but supports it!

# Supported game versions
* gta3.exe v1.0.
* gta3.exe v1.1.
* gta3.exe v1.1 Steam.
